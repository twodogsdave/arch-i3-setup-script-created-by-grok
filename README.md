# arch-i3-setup-script-created-by-grok

I used Grok to create a i3wm setup script for a fresh Arch Linux install.

The script installs i3 and all the other 'little things' I need for a proper setup.

The script also installs all my favorite apps as well as Nvidia, bootloader and display manager.

Enjoy!

Note: This is for MY laptop.  If you use this script, some things might need to be changed.
